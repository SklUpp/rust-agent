# Модульное переиспользование: автономный tool-first профиль (`arag`)

Дата: 2026-11-20 (выверено скаутами по `Cargo.lock`, исходникам `~/rust-agent` HEAD `36c0fe3`, донору `~/omp-work` `18.0.9` / `3008cfd0ca` и манифестам внешних репо). Нормативная фиксация выбора — в [agent-architecture-decisions.md](agent-architecture-decisions.md) («Согласование 2026-11-20»); привязка к срезам — в [agent-preliminary-implementation-plan.md](agent-preliminary-implementation-plan.md).

Цель: мощный автономный tool-first агент на Linux и Termux/Android (Bionic arm64) на базе `~/rust-agent` без переписывания ядра, без потери возможностей (`bash`, тулы, `eval`, субагенты) и с выносом тяжёлого нецелевого балласта под Cargo features.

- Из внешних проектов: verbatim extract `codex-execpolicy` (тащит `starlark 0.14.2`) и `codex-linux-sandbox` (тащит 5 внутренних `codex-*` крейтов), `codex-apply-patch` (дубль `hashline`/`edit_variants`), встроенный `rhai`/`rquickjs` для хуков, локальный ONNX/fastembed.

Райдер не является OSI Open Source, имеет приоритет над MIT, вирусный для любых Derivative Works, запрещает доступ/анализ/использование в автоматизированных системах и eval-контурах в связи с `OpenAI`/`Anthropic` и их аффилиатами/агентами, предусматривает автоматическое прекращение лицензии с уничтожением копий и возмещение `attorneys' fees`. **Исключён полностью** (не копировать код, не копировать паки правил и не рекомендовать как штатный hook для агента, работающего с моделями OpenAI/Anthropic).

## 4. Привязка к плану `R0–R12`

1. **Подготовка / `R0–R2`:** мигрировать workspace с `reqwest 0.12` на единый `reqwest 0.13` (`rustls-no-provider`) + `rustls::crypto::ring::default_provider().install_default()` (удаляет `aws-lc-sys` и `cmake`), закрыть хвост `R1` и `R2`, внедрить Cargo features (`core-grammars`/`full-grammars`, `direct-providers`, `dap`, `security-scan`).
2. **`R3`:** опереться на уже существующие `pi-shell/src/process.rs` и `workspace_writer.rs`, подключить `process-wrap` + `crash_handler.rs` (переименовав `.omp`/`PI_*`) + прямой `termux-wake-lock`, затем портировать matcher `prefix_rule`/`host_executable` (без `starlark`) + базовый MIT-набор правил деструктивных команд поверх `brush-parser`, добавить seccomp-BPF network kill-switch (`seccompiler`, работает и на Android, и на Linux) и `landlock`/`bwrap` строго под `#[cfg(target_os = "linux")]` (на Android `landlock_*` даёт `SIGSYS`).
3. **`R4–R5`:** извлечь `utok/` (с `utok-all-families` под feature), портировать Aider RepoMap поверх `pi-ast` + ленивый LSP (`R4`), портировать `mnemopi` на `rusqlite` FTS5 (со скоупами `global`/`project`/`session`) + `vectors.rs` + опциональный 9Router `/v1/embeddings` (`R5`).
4. **`R7–R8`:** перенести `pi-vcs/src/git` (без `jj-lib`) + `diffy::merge` 3-way merge + `[PENDING_APPLY]` поверх готового `conflict://` + size cap на не-git `Rcopy` (`R7`); нейтральные subprocess JSON hooks (`R8`).
5. **`R9–R12`:** перенос lock root `workspace_writer.rs` и данных `~/.omp → ~/.aragent` (`R9`), `/retry` (`R10`), `arag doctor` (`R11`), inline-reflow в `tui.rs`, релиз `0.2.0` и прогон в `metaharness` (`R12`).

## 5. Проверка границ и ограничений

- Наличие модуля у донора не доказывает сборку или работу под Bionic arm64; каждый перенос принимается только с тестами и проверкой CI (`x86_64-unknown-linux-gnu` + `aarch64-linux-android`).
- При каждом заимствовании фиксируются точный commit/version донора и атрибуция в `THIRD-PARTY-NOTICES.txt`.

## 6. Актуализация 2026-11-26 (по итогам R1–R3 и анализа зависимостей R4–R8)

- **R0.1–R0.3, R1 (`0ec6d99`), R2 (`6828ab0`), R3 (`c309722`)** закрыты в CI (`45827228390`, `45839280446`, `45856046782`). Из R3 по решению пользователя пропущены `process-wrap` (дублирует готовый `process_group(0)` + `terminate_tree`) и kernel sandbox (`seccompiler`/`landlock`/`bwrap` — отложено вместе с `fastproot` после R8).
- **R4:** `utok` использует pure-Rust `ruzstd 0.9` вместо C `zstd` + `xutf 1.4` (уже в `Cargo.lock`); RepoMap использует `tree-sitter-tags 0.25` (совместим с `tree-sitter 0.25`) + свой power-iteration PageRank вместо `petgraph`/`stack-graphs`.
- **R5:** к FTS5 + `vectors.rs` + `/v1/embeddings` добавлен универсальный opt-in Cargo feature `local-embeddings` (`fastembed 7.8`, `default-features = false`, `onnx`, `ort-load-dynamic`, `hf-hub-rustls-tls`, `fancy-regex`) для всех таргетов включая Android (в дефолтных сборках выключен).
- **R7:** `pi-vcs/src/git` (`gix 0.85` без `jj-lib`, fallback на `git` CLI) + `xxh3`; для 3-way merge остаётся уже интегрированный в `task_isolation.rs` крейт `similar 3.2` вместо `diffy`.
- **R8 / R6:** R8 Hooks следует stdin/stdout JSON контракту Claude Code / Codex (`PreToolUse`, `PostToolUse`, `PermissionRequest`, `Stop`, `SessionStart`) с trust-gating проектных конфигов; R6 и macOS/Windows CI-матрица пока отложены.
